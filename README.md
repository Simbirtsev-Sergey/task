# Торговый сервис

REST API для торговли акциями, облигациями и валютными парами. Сервис принимает заявки на покупку и продажу, заключает сделки и показывает текущие цены в стакане.

## Запуск

Понадобятся JDK 21 и Docker Compose. Откройте PowerShell в папке проекта, задайте пароль для локальной базы и запустите сервис:

```powershell
$env:DB_PASSWORD = Read-Host 'Пароль локальной базы'
$env:DB_URL = 'jdbc:postgresql://localhost:55432/trading'
docker compose up -d --wait
.\mvnw.cmd clean package
java -jar target/trading-service-1.0.0.jar
```

API доступен по адресу `http://localhost:8080/api`. При первом запуске приложение создаёт таблицы. Для подключения к своей базе PostgreSQL 15 или новее задайте `DB_URL`, `DB_USER` и `DB_PASSWORD` и пропустите команду Docker.

## Пример сделки

На пустой базе откройте [examples.http](examples.http) в IntelliJ IDEA и выполните запросы сверху вниз. Продавец выставляет 30 акций по 100 ₽. Покупатель готов взять 20 акций по цене до 101 ₽. Сделка проходит по цене продавца - 100 ₽ за акцию. В стакане остаются 10 акций. Последними двумя запросами можно изменить цену остатка и снять его с торгов.

## Правила торгов

- Количество единиц актива должно быть кратно размеру лота, а цена - шагу цены инструмента.
- Для покупки сервис резервирует деньги, для продажи - актив. При отмене заявки остаток резерва освобождается.
- Сначала исполняется заявка с лучшей ценой. При равной цене первой исполняется заявка, поступившая раньше.
- Для операций со своими заявками и чтения счёта передайте идентификатор владельца в заголовке `X-User-Id`.

## Почему JDBC

Spring JDBC позволяет явно задать SQL для двух основных операций: поиска лучшей встречной заявки и расчёта стакана. PostgreSQL суммирует объёмы по каждой цене, поэтому приложение получает готовые уровни стакана. Перевод денег, передача актива и запись сделки проходят в одной транзакции.
